GAMER PRO KIT - Version 2.0

HOW TO OPEN
1. Extract the ZIP file.
2. Open the GAMER-PRO-KIT folder.
3. Double-click index.html.

FEATURES
- Game starter presets (prefill game/platform only; customize your settings)
- Gaming Settings Tracker
- PC Performance Log (manual FPS entries; no automatic measurement)
- Mobile HUD Planner with draggable controls, saved layouts and PNG export
- Gaming Progress Tracker
- Statistics dashboard based on manually entered records
- JSON backup and restore for settings, performance, progress and HUD layouts

DATA & LIMITATIONS
Data is stored locally in the current browser using localStorage. It does not sync online.
Export a backup to move data to another browser/device. Clearing browser data can erase records.
Performance values are entered manually. The app does not connect to games, read game memory,
or automatically measure FPS. HUD layouts are planning previews, not in-game modifications.

This is a prototype and should be thoroughly tested before commercial sale.
